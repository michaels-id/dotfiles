## My development environment
My favorite programming language is [Rust](https://rust-lang.org/).

### Hardware
- Notebook: MacBook Air M4 
    - Great CPU performance at a low price (Rust Compiler benefits from fast single-core performance)
- Monitor: KTC H27P3 27" 5K
    - 218 ppi for sharp text display at low price (94 ppi was fine for Windows, but not for macOS)
- Keyboard: Logitech Ergo K860
    - Ergonomic comfort
- Mouse: Kensington Expert Mouse Trackball
    - Ergonomic comfort (Note: For heavily GUI-focused work I still prefer a normal mouse for quicker, more precise movement.)

### History
Inspired by [Jon Gjengset](https://github.com/jonhoo) I started a keyboard-focused workflow with NeoVim. In the beginning it was hard to remember all those shortcuts, but with time I really liked it.  
Later I decided to switch back from NeoVim to VSCode, which is our default editor at work. But I customized it for a minimalistic look with Vim keybindings (see [here](https://github.com/michaels-id/dotfiles/tree/main/private_Library/private_Application%20Support/private_Code/User)).
