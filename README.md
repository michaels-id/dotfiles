## My development environment
My favorite programming language is [Rust](https://rust-lang.org/).

### Hardware
- Notebook: MacBook Air M4 
    - Great CPU performance at low price (Rust Compiler needs fast single core performance)
- Monitor: KTC H27P3 27" 5K Monitor
    - 218 ppi for sharp text display at low price (94 ppi was fine for Windows, but not for MacOS)
- Keyboard: Logitech Ergo K860
    - Ergonomic comfort
- Mouse: Kensington Expert Mouse Trackball
    - Ergonomic comfort (Note: For heavily GUI-focussed work I still prefer a normal mouse for quicker, more precise movement.)

### Software
- [VSCode](https://code.visualstudio.com/) as GUI IDE
- [NeoVim](https://neovim.io/) as Terminal IDE
- [Chrome](https://www.google.com/intl/en-us/chrome/) as Web-Browser
- [Gemini](https://gemini.google/desktop/) as AI for questions
- [Obsidian](https://obsidian.md/) as Markdown Notebook

### History
Inspired by [Jon Gjengset](https://github.com/jonhoo) I started a keyboard-focussed workflow with NeoVim. In the beginning, it was hard to remember all those shortcuts, but with time I really liked it.  
Later I decided to switch back from NeoVim to VSCode, which is our default editor at work. But I customized it for a minimalistic look with Vim keybindings and lots of custom Vim shortcuts (see [here](https://github.com/michaels-id/dotfiles/tree/main/private_Library/private_Application%20Support/private_Code)).
